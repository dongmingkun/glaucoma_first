## 五、推荐（唯一一份）
**首选 `soup3_test_tta4_ens10_logit_w10.csv`（md5 `6e00216d`，ens10×0.9 + soup3×0.1）**
理由：
1. **机制与前两次不同**：前两次（seed7 单 seed、seed7+seed42 概率平均）都在 98.84 打平；soup3 是**三个 seed 的权重空间平均**，是这条家族里唯一没被线上检验过的聚合方式；
2. 风险最低的一档：top200 **200/200**、rho 0.9968，排序主体不动，只是把「第 3 个 seed 的权重信息」以权重平均形式掺入；
3. 校准最稳：mean 0.0841 与 ens10 的 0.0830 只差 1.3%（soup3 单独 mean 0.1008 偏高，但 w10 只掺 10%，影响被稀释）。

**备选 `cnxb_512_e16_ra_all_s123_test_tta4_ens10_logit_w10.csv`（md5 `6e3e466a`）**：若想「干净地只检验第 3 个 seed 是否带来新信息」，选这份（rho 0.9975 / top200 200）。

**明确不建议**：
- `avg3×ens10 w20`（rho **0.9997**）——与已提交的 ID 21547 几乎是同一份文件，投它等于确定打平；
- `soup3`/`s123`/`avg3` 单模不融合（rho 0.87–0.90）——会把 ens10 的整体结构换掉，风险与收益不匹配。

**判负线**：三次同家族提交都停在 98.84，本条线**先验上大概率仍是 98.84**。若只剩 1 次配额且更看重稳妥，建议**不投**、保留 98.84；若愿意用一次配额换「机制确认」，投 `soup3×w10`。
