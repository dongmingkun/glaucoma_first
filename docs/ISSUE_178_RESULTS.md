# Issue #178 结果 — Large384/512 多尺度 TTA 候选

## 结论（先说结果）

1. **多尺度 TTA 已跑通，且不是空操作**：同模型 448↔576 秩相关仅 0.929（L512）、352↔448 为 0.945（L384）；  
   多尺度平均 vs 单尺度 rho = **0.9926（L512）/ 0.9907（L384）**。
2. **与 D1 融合后位移很小**：三个工单候选 rho = 0.99992 / 0.99953 / 0.99925，top200 = 198 / 196 / 198（对 D1 重建）。
3. **没有正收益证据**：Large 是 train+all，无干净 valid；ms 只改了 2–4 张 top200 图，历史上同档位移（#157 B1 rho 0.9933/top200 198、#168 V6a rho 1.0）线上均打平。  
   **建议：不建议把配额优先给 ms 候选**，先投 D1 本身；若想一次同时验证 D1+ms，选 **v1**（位移最小）；若要最大化 ms 暴露，选 **v3**（双 Large 全部换成 ms）。
4. **D1 原件/口径说明**：本机没有官方 D1 `e0f7e829`（在队长机器）。候选是用公开成员 + 本次自算 Large 概率构建的独立完整融合，不是对官方 D1 打补丁。  
   ⚠️ **后续 #180 审计纠正**：本文件的 D1/L1 重建用了「best/last 先概率平均再 rank」的 RA_avg 口径，导致 max_err≈0.0593；#180 证明改用「先各自 rank 再 0.5/0.5 平均」可 byte-level 复现 L1（`e244a37e`）与 D1（`e0f7e829`）。因此本文件的 D1 重建只是近似，ms 候选相对官方 D1 的 rho 会有小偏差；**但 ms 无正收益的结论不变**。
