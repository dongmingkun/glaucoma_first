## 2. RA_soup 溯源（工单要求的第 1 项）

工单要求「确认 RA_soup 由 RA_best+RA_last 0.5/0.5 **权重平均**得到，不是概率平均」。用概率文件做了可判定的检验：

| 量 | 值 |
|---|---|
| 行数 | 5,855（官方顺序） |
| 与 `(best+last)/2` 概率平均不同的行 | **5,855 / 5,855（100%）** |
| 平均绝对差 | **0.0313** |
| mean：soup / 概率平均 / best / last | **0.08149** / 0.05325 / 0.05514 / 0.05136 |

- 概率平均的 mean 必然 ≈ best 与 last 的均值（观测 0.0533，符合）；**soup 的 mean 高出 0.028**，且逐行全不同 —— 这是权重平均后重新前向的典型特征（BN/EMA 统计与参数插值共同作用），**确认是权重空间 soup，不是概率平均**；
- 与此前 #145 记录一致：soup 会把校准 mean 从 ~0.05 抬到 ~0.08，**AUROC 口径不受影响，但 0.5 阈值 Pred_Label 需重校准**（本单所有候选都走 rank 融合 + mean 归一到 0.5，规避了该问题）。
